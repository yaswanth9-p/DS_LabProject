# MBU Lab Hub

Create a premium, modern, responsive student laboratory website for Mohan Babu University, designed with a strong Apple-inspired / iOS aesthetic.



The website should feel like a combination of an Apple product website + iOS app dashboard + modern university student portal. Prioritize simplicity, elegance, smooth animations, excellent typography, spacious layouts, glassmorphism, subtle shadows, and intuitive navigation.



1. DESIGN LANGUAGE



Use an Apple-inspired visual design:



- Clean and minimal UI

- iOS-style cards and panels

- Soft glassmorphism

- Subtle backdrop blur

- Large rounded corners

- Very soft shadows

- Premium spacing and alignment

- Smooth hover and click animations

- Fluid page transitions

- Minimal borders

- Elegant micro-interactions

- Responsive on mobile, tablet, and desktop

- Avoid clutter and excessive colors



Use an Apple-like system font stack:



"-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Helvetica Neue", Arial, sans-serif"



Typography should resemble Apple's website:



- Large bold headings

- Clean medium-weight body text

- Strong visual hierarchy

- Comfortable line spacing

- Minimal text decoration



Use a sophisticated color palette:



- White

- Off-white

- Very light gray

- Graphite/black

- Apple-style blue as an accent

- Subtle gradients

- Optional dark mode



The website should support Light Mode and Dark Mode, with a smooth transition between them.
